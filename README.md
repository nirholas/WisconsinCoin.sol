# WisconsinCoin — Wisconsin's first cryptocurrency

In dedication to my first day of business school I launched WisconsinCoin (WISCO), an ERC-20 Ethereum token with a fixed supply of 5,790,000 coins — the population of Wisconsin.

## Status

This repository is a placeholder: it documents the project but does not contain the contract source. There is nothing here to install or build.

## Deployment

The WISCO test contract was deployed to the Ropsten testnet at address
`0x944c822831334ee051b9e5dc86dc764bb6f7b878`.

Ropsten was deprecated and shut down in late 2022, so the original block explorer link no longer resolves and the deployment is no longer reachable. The address is kept here for historical reference only.
